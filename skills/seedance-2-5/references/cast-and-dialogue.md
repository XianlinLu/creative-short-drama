# 从人物定型到逐段视频的画布连线

适用于在火山引擎 Lumi 和 BytePlus Lumina 实际制作有角色的短剧。写入节点或修复旧画布前读取[双画布连线与验收](canvas-connections.md)。写完《创作与分镜方案》后先做选角和录音，整集人物资产通过确认后再开首段。只委托编剧或分镜时交付方案；进入媒体制作时，向用户展示图片、试音、正式对白的数量和费用，并沿用已取得的对应授权。

## 从定稿建立角色表

逐场读动作、对白、画外音与旁白，按角色身份合并别名，覆盖一次出场、无台词和仅画外发声的角色。记录每人在哪些镜头出镜、在哪些镜头发声。给每句正式对白保留说话人、逐字原文、场号、镜号、表演提示与发声窗口。字幕、舞台说明和视觉动作不会自动变成台词。

1. **先完成全体三视图。** 给剧本每个角色生成独立图片节点，一张图并列同一人物的正面、侧面、背面全身。三栏保持同一服装、体型、比例、光线和尺度。核对全部图像均已就绪、各角色可辨认，再进入试音。已有本版合格三视图可复用其真实节点。
2. **逐人生成试音。** 从该角色三视图节点向对应试音节点建立可见输入连线，并在试音任务中实际绑定该图。每人生成约 20 秒、单人、干净、可单独播放的音频，用与角色相符的短句试听平叙、停顿和情绪变化。声音设计发生在此步。核对图与声音归属，保存试听结果和实际时长。无正式台词的角色也保留选角试音，成片只用剧本规定的声音。
3. **用试音录正式台词。** 试音就绪后，将该角色试音的音频输出直接连到每个对应正式台词节点的参考音频或音色输入。在节点字段绑定这一条试音；生成提示词只含表演语气、语调与剧本原句。举例：表演指令「先迟疑半拍，后半句轻轻上扬」，朗读原文「你还记得那天吗？」。两者分栏，仅朗读原文。音色、年龄感和声质形容词都留在试音阶段。按说话人及段落分轨，听清原文、停顿、身份与实测时长，不把试音文案混入正片。
4. **首段前让用户核准整套资产。** 在画布按角色展示三视图、可播放试音、全部已录台词和对应镜号。检查漏角、漏句、串音色、时长超窗和断线。支持整批确认；有改动时重做受影响的一支。只有用户明确确认这一版人物、试音、台词及其连线后，才创建首段视频。单纯批准剧本或事先授权费用不能替代此次确认。

## 逐段绑定并回读

| 本段需要什么 | 直接连到本段视频节点的输入 |
| --- | --- |
| 分镜与镜头表演 | 含本段镜号、时长、动作与台词落点的画布分镜文本节点。由同版方案派生，保持可追溯 |
| 本段出镜角色 | 每位出镜角色的定稿三视图；仅画外发声的角色按声音引用 |
| 本段对白或画外音 | 对应角色、对应句子的正式台词音频。按镜内时序绑定，避免再次合成人声。无台词段跳过此类输入 |
| 其他已选素材 | 本段实际使用的场景、道具、关键帧、声音等节点 |
| 第二段起的连续性 | 上一段已就绪的真实视频输出，接入当前视频延长模式；同时重连上面各项本段所需输入 |

在每个目标节点执行前，用宿主 ba-canvas 的实时能力检查输入类型、槽位数量和组合，然后写入实际边与对应的生成输入。写入后回读画布图及节点绑定，按“源节点和资源、目标节点和输入用途”逐项核对。仅在 Note 画箭头、在提示词中写文件名、仅作展示的连线或只把素材接到预览节点，都不能作为验收依据。宿主不支持图入试音、参考音频继承、文本接视频或延长时并用必要输入时，明确指出缺少哪条边或哪个输入能力，停在该处等待选择。不得静默删边或改用文本模仿音色。

例如第一段是两人同框、一人说话，直接连接两张三视图、说话人的正式台词和第一段分镜。第二段只拍其中一人、另一人画外回答，就连接上段实片、本段出镜者三视图、画外回答的正式录音和第二段分镜。每轮只提交当前视频节点，未来视频段留在方案中。恢复任务时先回读现有节点和已批准版本；改台词只重录受影响的句子，更换试音则重新核对依赖该音色的正式台词和视频。
