# 电商与广告

通用执行与 Prompt 规则按主文件必读项执行；本文仅补充广告机制、产品一致性、证明与商业版本策略。

用于商品广告、品牌短片、信息流、UGC 风格广告、零售、本地生活、多 SKU 和多门店素材。

## 一、最小输入

- 产品真实图片或视频；
- 目标受众和使用场景；
- 一个主痛点或欲望；
- 一个主卖点；
- 可验证的演示、数据、证言或证明；
- 品牌调性、禁用表达和 CTA；
- 渠道、比例和已有片长要求；未指定片长时，待脚本、粗分镜与计时后推荐。

没有证明材料时，不编造实验、用户证言、数据、认证或 Before/After。

## 二、先选广告机制

- 痛点演示；
- Before/After；
- 产品测试或挑战；
- 使用教程；
- 用户证言；
- 结果先行；
- 拆箱或发现感；
- 场景化欲望；
- 品牌故事或情绪记忆。

内容不必全部以销售为导向。品牌片可以把 CTA 替换为记忆点、态度或场景联想。

## 三、基础信息结构

电商和效果广告优先：

```text
Hook → 痛点/欲望 → 产品出现 → 使用演示 → 结果/证明 → 异议处理 → CTA
```

品牌广告可用：

```text
情境/冲突 → 品牌介入 → 体验变化 → 情绪或价值落点 → 品牌定帧
```

每个镜头优先服务一个主要信息目的。让人物拿起、使用、比较或观察产品，使产品参与过程，而不只是结尾的一张静物图。先展开事件、动作、口播/旁白和声音，再写粗分镜；依据演示完整性、自然语速和证明阅读时间确定片长。渠道硬性时长已知时，主动选择信息优先级，避免把所有结构节点硬塞进短广告。

## 四、时间结构示例

以下假设内容计时后确定为 20 秒，仅展示定时分镜，不代表必选片长或单次生成时长。

```text
0–3 秒：人物遇到____问题，画面出现____可见后果，产品同时进入画面，让观众想知道它如何解决问题。
3–7 秒：人物拿起产品，按真实使用方式完成____操作；动作开始时配合____音效。
7–13 秒：近景拍清操作、产品响应和____结果；旁白用一句话说明主卖点“____”。
13–17 秒：展示用户提供的____证明，回应“____”这一关键疑虑；留足看清证据的时间。
17–20 秒：产品稳定展示在____位置，品牌信息与 CTA“____”由真实素材或后期加入。
```

有硬性时长时据此重排内容；没有时长要求时根据实际脚本重新计时，不套用此分配。Hook 应包含具体画面事件、观众关注点和后续回报，不能只写“更有冲击力”。信息段、镜头和生成任务分别规划；一条广告需要多轮生成时默认沿同一产品和转场载体建立串行延长主链。独立证明素材只有在它本来就是不同真实来源，或用户确认硬切／并联路线时才分段组合；普通换景不自动产生并联视频节点。

## 五、产品一致性

- 产品外形、包装、颜色、标识、接口、配件数量和使用方式与输入素材保持一致；
- 关键标签、价格和 UI 用真实素材或在后期叠加；
- 在产品承担信息或演示的关键镜头中，让外形、使用方式和结果清晰可识别；
- 运镜、人物和特效不能抢走观众对核心操作的注意力；
- 针对液体、食物、服饰、美妆和机械产品，分别补充必要的材质表现、贴合关系、遮挡关系和物理响应；
- 需要批量换产品时，先在方案与素材层面核对母版构图和动作能否容纳不同 SKU；生成后的试制验收按已确认流程进行，不额外创建自动重抽轮次。

## 六、证明优先级

优先使用：

1. 真实可复现演示；
2. 真实结果或对比素材；
3. 真实界面和数据；
4. 已授权证言；
5. 最后才是纯口播主张。

事实内容与氛围内容分开。生成模型可表现使用情境和视觉隐喻，不负责捏造医学、功效、性能、价格或认证事实。

## 七、多版本生产

仅在用户明确要求多版本时建立变量矩阵：

```text
Hook | 痛点角度 | 演示方式 | 证明方式 | 人物/场景 | CTA | 比例 | 语言
```

首轮选择能区分假设的少量版本，不穷举所有组合：

- Hook 表现差：只换开头；
- 中段流失：压缩解释，提前演示；
- 点击高但转化弱：强化证明、异议处理或报价连续性；
- 创意疲劳：换场景、人物或执行形式，不只是滤镜和字幕颜色。

版本名记录唯一主变量，例如：`hook-result-first_v2`。

## 八、门店与 SKU 批量素材

- 建立一个可替换的母版；
- 把产品、门店背景、优惠、地址、CTA 设为独立变量；
- 不让背景替换改变产品光影逻辑；
- 每个门店或 SKU 使用对应真实素材；
- 优惠、库存、币种和落地页必须一致；
- 先验证一个变体，再批量执行。

这里的验证先检查素材、变量和方案是否完整；如需要付费试制或生成结果验收，按既有授权及基础画布交接规则安排，不因此新增自动观感质检或等待流程。声音方案包含必要对白、旁白、环境音与动作音效；没有用户要求时不自动加入配乐。

## 九、专项检查

- 首屏是否能识别产品、痛点或欲望；
- 是否形成完整的信息结构；
- 功能、数据、优惠和证明是否都有输入依据；
- 每个版本是否只有一个主要实验变量；
- 产品参考、证明素材、文字和 CTA 是否已绑定；
- 是否明确需要的比例、语言、字幕和无字幕版本；
- 证明和 CTA 是否留足阅读时间；
- 时长是否由内容计时或明确渠道约束得出，未机械套用示例；
- 是否把精确文字、价格和标识交给真实素材或后期。
