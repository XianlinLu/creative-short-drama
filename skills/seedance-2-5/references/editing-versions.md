# 编辑与版本化

通用执行与 Prompt 规则按主文件必读项执行；本文仅补充编辑分流、原片保持边界、延长接续、转场与版本交付方法。

用于原片局部修改、参考图编辑、音频编辑、延长、两段视频转场和批量版本交付。

## 一、原片编辑与参考重做先分流

### 原片编辑

用户要保留原视频的时间线、镜头、动作、节奏、时长或比例，只增删改指定内容。进入实时能力提供的视频编辑模式。

### 参考重做

原视频只提供人物、动作、运镜、风格、节奏、剧情或传播机制，用户接受重新组织镜头、场景、时长和比例。进入多模态参考生成。

同时出现“其余不变”和修改比例、时长或镜头时，先识别能否通过精确裁剪、重构图或局部后期满足，并按实际模式判断保持能力。只有要求之间仍互相排斥时，才就具体保持项与改动项澄清，不默认要求用户在整片不变与整片重做之间二选一。

## 二、编辑指令

每次编辑写清：

```text
【范围】时间段、镜头、区域或对象
【修改】改什么、改成什么、发生过程和连带变化
【保持】时间线、人物、动作、镜头、构图、光线、场景、声音中哪些不得变化
```

### 常见编辑

- **换背景**：补充新环境光、反射、阴影、遮挡和边缘融合；
- **换人/换装**：保留动作与身体比例，衣物贴合原身材，匹配原画风与光线；
- **改道具/产品**：保持握持、接触、数量和操作逻辑；
- **删元素**：多镜头时明确每个镜头都删除；
- **改运镜**：只改相机路径，声明人物、动作、视觉风格和剧情不变；
- **改色调/材质**：保留纹理和原有光影关系，说明受影响对象范围；
- **音频编辑**：明确保留对白、环境音、音效或音乐中的哪些轨道。

优先一次只改一个主要变量。多个独立修改按用户确认的范围和相互影响决定合并或分轮，不为形式上的单变量增加不必要的生成任务。原片编辑先遵守时间线、动作、声音和节奏保持项，不擅自变速或强行切镜。

音频编辑中的去除 BGM 不等于静音：定向处理音乐层，保留需要的环境音、动作音效和用户确认的对白/旁白。用户指出素材仍有 BGM 时，确认音乐层修复方案，不直接静音，以免丢失人声和音效。

## 三、延长

延长用于保持连续主体、产品、动作、表演、空间、运镜或声音。一条成片需要多轮生成时，按[串行延长主链](sequential-extension-chain.md)先只提交起始段，得到真实源片后一次创建一个延长节点；不得预建未来段或把多个普通视频节点并联后再拼接。同一模型生成的源片可优先继续延长。明显时空断点先尝试设计转场桥；只有用户明确确认独立路线、上游问题不应继承或实时能力确实不支持时，才另行生成或新开延长链。

规划时先写新增内容的事件、动作、声音与创作分镜，再计时并设计整条延长主链。完整计划写入 Note／任务表，节点只实例化当前可执行的一段。起始段需建立后续要继承的主体、空间、光线与声音基线，并在自然叙事位置留下可识别接续点。已有源片长度作为实际起点；新增时长由内容与已确认交付约束决定。

延长任务记录真实源视频边界状态：

- 人物位置、朝向、动作和情绪；
- 场景、时间、光线和天气；
- 相机位置、运动和景别；
- 道具与产品状态；
- 声音与节奏；
- 下一叙事节拍。

提示词说明：当前模式支持的延长方向、如何衔接、新增事件、镜头如何继续、声音如何接续以及目标结束状态。每轮要有清楚的推进目标，允许完成多个短节拍或长节拍的一部分，不强制一轮、一个镜头、一个节拍相等。

```text
延长方向：在当前模式支持的方向上向____延长____秒，源视频为【接续源片】。
接续边界：人物位于____，朝向____，动作进行到____；道具/产品处于____状态；场景光线为____，相机位于____并沿____方向运动。
接续过程：从____动作/视线/声音节点承接，人物随后____；镜头沿____路线继续，以____方式进入下一事件____。
声音接续：____对白/环境音/动作音效在____位置继续或交接，与____动作同步。
目标结束状态：人物停在____，道具状态为____，相机落在____景别，以____节点结束，供下一段规划使用；生成后需以真实边界为准。
```

【接续源片】为素材职责占位，执行时按基础画布绑定真实资源。分段计划分别记录镜头编号、任务编号、内容所需长度、实际生成长度、接续方式、真实来源和下一事件。计划结束状态与实际边界状态分开保存；通过基础画布的媒体理解路由完成下一步所需的最小接续分析，未知项明确标记，不从上一版 Prompt 推测结果。

必要的接续分析不同于自动观感质检，不因此增加评分、重抽或等待式查询。任务提交、交接与恢复遵守基础画布生命周期。最终成片是需要裁剪、拼接，还是可以直接使用延长结果，应根据实时能力说明的输出内容决定，避免重复拼接原片。

## 四、无缝转场

输入两段视频时：

1. 找到前片结尾和后片开头可连接的动作、形状、颜色、遮挡、光线或声音；
2. 写清转场触发时刻；
3. 写清视觉变化路径；
4. 声明原视频片段哪些内容不得改变；
5. 无可靠连接点时使用硬切或精确后期处理，不强求生成式转场。

示例骨架：

```text
前片在主体完成____动作的____时刻触发转场；镜头沿____方向移动，画面中的____通过____遮挡/形状变化逐渐接到后片的____；前片的____声音延续到____位置，再由后片的____声音接上。生成范围仅为中间____秒衔接，两段原视频的主体内容按原样保留。
```

## 五、批量版本化

仅在用户明确要求多版本或批量交付时，先建立 Master，再定义变量：

- 主体或 SKU；
- 场景或门店；
- Hook；
- 语言和市场；
- 价格、优惠与 CTA；
- 比例、时长和字幕；
- 人物或品牌调性。

每个版本只改变声明的变量。先核对代表性版本的方案、素材映射与规格；需要试制时按已确定流程评审与续接，不自动增设付费验收或重抽任务。

建议命名：

```text
项目_市场_语言_比例_时长_主变量_v01
```

## 六、多比例和多时长

- 不直接把横屏中心裁成竖屏；先确认主体、文字和产品安全区；
- 竖屏可重新构图或使用背景填充；
- 制作短版时，不要简单截断原片，而应重新选择 Hook、核心演示、证明和 CTA；
- 为新短版重新形成脚本与粗分镜，计时后再确定剪辑点；原版有严格保持要求时不以“优化节奏”为由擅自改动；
- 精确字幕、Logo、价格和 CTA 在后期放置；
- 各比例版本保持同一 Master 的事实和品牌资产。

## 七、后期分流

下列需求交由精确剪辑或后期处理，当前工具选择及中间画布结构由基础画布工作流确定：

- 精确裁剪、删除瑕疵；
- 需要精确控制或输出最终资源的多段拼接；
- 字幕、Logo、价格、步骤号和 UI 标注；
- 已要求的配乐、混音和声音淡入淡出；
- 多轨、画中画、滤镜、动画和最终导出；
- 需要精确时长和帧级剪辑。

生成模型负责创作画面和生成式编辑；简单顺序串联与精确后期按通用流程及基础画布路由区分。需要精确到时间码、帧或轨道的处理交给适用的剪辑工具；选用 VividCut 时仍保留基础画布要求的阶段预览或顺序载体。没有用户要求时不新增音乐。

## 八、专项检查

- 是否明确原片编辑或参考重做；
- 编辑是否写明范围、修改项和保持项；
- 原片时间线、动作、声音和节奏保持边界是否清楚；
- 音频编辑是否只处理指定轨道而保留其余声音；
- 延长是否分别记录真实边界、待推进事件和目标结束状态；
- 延长输出是否明确包含哪些片段，避免重复拼接；
- 转场是否有触发点和变化路径；
- 版本矩阵是否定义单一变量；
- 各版本的字幕、语言、CTA、比例和文件名是否可追踪；
- 需要精确剪辑的任务是否已进入适用后期路线，阶段结构是否服从基础画布。
