# 短剧与漫剧导演工作流

本篇及配套的前期、制片和交付指引，是 Creative Short Drama Director 为本项目独立编写的原创流程说明。

## 从用户手上的材料开始

| 环节 | 适合的请求 | 当前阶段交付 | 下一站 |
| --- | --- | --- | --- |
| 项目统筹 | 开新剧、接上次工作、改配置、查看进度、打包 | 项目简报、分集目录、制作形态、版本及进度 | 根据已有材料进入对应环节 |
| 原著分析 | 小说、连载、某一卷或一段章节 | 有原文定位的章节记录、人物变化与候选分集 | 故事开发 |
| 对标与还原 | 学习参考片节奏、反推脚本、对比两集 | 实测与看片笔记、可迁移手法、按需还原文档 | 开发或指定环节 |
| 故事开发 | 一句话、梗概、改编提案、已有多集稿 | 创作简报、导演阐述、分集走向与集尾交接 | 单集编剧 |
| 单集编剧 | 写一集、改一场、缩短对白 | 分场剧本、发声人与画面文字、估时 | 视觉设定与创作分镜 |
| 视觉设定 | 提取人物、服装、场景、道具和声线 | 按生效场次组织的设定及连续性要求 | 图片提示词、分镜 |
| 图片提示词 | 人设图、定调图、变体、局部修改、关键帧 | 每张图的用途、输入与可复制的静态描述 | 已确认资产制作或分镜 |
| 分镜设计 | 从场次拆镜头、安排视线、首尾帧和切点 | 定时分镜、出场设定、逐镜首帧与必要尾帧 | 视频与声音提示词 |
| 视频与音乐提示词 | 写动作、配音、配乐或多镜段落 | 含镜内时间和声音职责的当前任务描述 | 投产预览 |
| 素材生产 | 做图、生成或延长视频、录制配音与配乐 | 当前批次预览、授权与真实任务回执、就绪资源 | 下一延长段或后期 |
| 剪辑成片 | 已有片段、关键帧或音轨 | 剪辑单、字幕、混音、成片文件与技术实测 | 验收交付 |
| 独立审查 | 审稿、查穿帮、诊断成片或验收返修 | 有定位和证据的问题单、修订范围、复审结果 | 回到最早引入问题的一环 |

有角色的画布短剧在定时分镜后进入[人物资产制作与连线](cast-and-dialogue.md)，全体三视图、逐人试音及全部正式对白确认后才进入视频投产。

做哪一环，就读取该环的上游产物。单段参考分析、单张设定图提示词或单场改稿可直接交付。完整项目按集维护《剧本》《视觉设定》《分镜》《图片提示词》《视频提示词》，进入后期再写《剪辑单》。画布上可用同一 Note 的六个分节承载；分开保存时用稳定的场号、镜号和资产名相互引用。交接注明正文版本、创作者已定的选择、待决定项、当前可执行范围和下一步。

## 项目配置、创作台与版本

立项时登记受众、集数、时长、语言、画幅、制作形态、音乐和人声需求、素材用途及交付目标。用户已经明确的条件直接生效。按集登记已确认的对白语速、节奏目标、目标模型、提示词语言、单段容量、多镜模式和接续路线。新建分集时为五份文档建立空白分节，按场号和镜号列出缺项；已有文档只补缺项。开放的创作选项先作为提案；实际投产核对宿主能力和已确认规格。恢复已有项目先读当前集、上集结束状态、已有媒体和任务记录。只在请求的集数范围内更新，局部修订保留原编号。

用一个代表镜头试定视觉方向。实拍重视光源与表演，二维动态漫区分固定背景、活动层和视差，三维先定空间体量与相机，水墨先定墨色层次与留白，Q 版先定头身比例与表情幅度，国漫动画先定线条、服装轮廓与动作节奏。把创作者选中的美术方向、参考用途和沿用范围登记到《视觉设定》。需要实际试图或试片时纳入投产预览。

看进度时按集列出每份产物的状态、版本、上游、现有素材、最后一次授权及阻塞项。画布中以可编辑 Note 展示；本地项目可用构建所得的 index.html 浏览本集文件，修改原稿后重新编译。导出可交付的文档和用户选定的媒体，按相对路径建清单并核对摘要。参考学习素材、凭据和临时资源地址不进入交付包。

- 视觉资产、静帧、分镜、动态与实际生成见[制片方法](production-desk.md)。
- 后期、审查、补拍与交付见[剪辑与审查](delivery-desk.md)。
