# 把视频提示词写完整

本文件只在内容母版已经完成创意、剧本、创作分镜循环，并取得必要用户反馈／委托和生产规格后读取。Prompt 是内容母版的执行翻译，不参与第一轮创作。若尚无通过的内容母版，返回[内容先行的三层循环](creative-development-loop.md)，不得用本文件模板或下方示例反推故事、片长和镜头。

以信息完整、没有歧义为目标，让人读完能想象出画面。复杂分镜、多角色、产品交互与长叙事展开动作、空间、镜头、光线、材质、声音和前后变化；简单动作或局部编辑只保留相关细节。长 Prompt 是复杂内容的结果，不是长度指标。精简重复、矛盾与无关说明，保留有效细节。

模板只是组织提纲，最终可以写成自然的导演说明。Prompt 来自当前版剧本、定时分镜与制作任务，不能用模板秒数反推故事。分段生成时，每个节点写全当前任务所需创作条件，使用任务局部时间线并说明前后接续；不把全片时间码误当当前任务时刻。长度遵守实时输入限制，接近上限时优先保留重要细节。

## 三层语言分别确定

- **对话语言**：覆盖进度、提问、方案、解释与最终回复。采用用户明确指定的沟通语言；未指定时跟随用户当前任务的自然语言。引用的英文素材、错误信息或外语台词不算用户切换沟通语言。
- **Prompt 叙述语言**：覆盖实际写入生成节点的镜头、动作、场景、声音与保持要求。采用用户专门指定的 Prompt 语言；未指定时与对话语言一致。不能只给用户看中文译文，却静默把实际节点 Prompt 改成英文。
- **视频内容语言**：覆盖观众实际听到的台词／旁白和看到的文案。按用户要求、已确认目标语言和需保留的原文分别决定；没有跨语言需求时可沿用任务语言，有歧义且影响内容时再澄清。无对白或无文字的部分不必虚设语言。

三层语言分别继承、分别修改。“用英文写提示词”不改变中文回复；“改成日语广告”不把镜头描述也自动翻成日语。用户明确的新选择只更新对应层；“继续”等短指令沿用已确定选择。无需每次向用户展示语言设置或重复询问。

| 用户请求 | 对话语言 | Prompt 叙述语言 | 视频内容语言 |
| --- | --- | --- | --- |
| 用中文请求普通中文广告，未指定 Prompt 语言 | 中文 | 中文 | 中文 |
| 用中文请求日语广告，未指定 Prompt 语言 | 中文 | 中文 | 日语 |
| 用中文要求英文 Prompt、日语台词 | 中文 | 英文 | 日语 |
| 用英文请求英文广告，未另行指定 | 英文 | 英文 | 英文 |

示例仅展示结构或局部表达，不是语言默认值。不得把参考文档或其他模型的英文字段要求迁移到 Seedance 2.5；也不得让节点 Prompt 的语言决定最终回复语言。若当前工具协议确有不可翻译的字段或固定值，只保留这些字段／值，不因此切换整段自然语言。

视频内容语言覆盖对白、旁白、字幕、标题、角标、CTA、免责声明，以及需本地化的招牌、包装、UI 与品牌副标。固定品牌 Logo、型号、商标、官方译名和不可改包装文字保持用户提供的准确形式，不擅自翻译或重绘。

外层制作说明用 Prompt 叙述语言，实际台词与显示文案直接用视频内容语言，并以引号、对白块或文字清单标出，不只写“翻译成目标语言”。例如中文用户要求日语视频时，写“人物看向镜头，用日语说：‘時間がない！’”，其余镜头描述和用户回复保持中文；只有明确要求英文 Prompt 时才改写外层描述。不把语言设置标签或制作备注生成进画面。

写入节点前检查实际 Prompt，发送消息前检查用户可见文本：外层语言是否符合各自约定，外语是否仅出现在指定台词、精确文字或必要专名中。发现无依据切换时在当前输出中改正，不重新征求用户已明确的语言偏好，不为纯文字修正自动触发付费重生成。

## 素材职责与参考方式

素材的可用性、用户修改要求与衍生资产准备先按[输入素材评估与资产准备](asset-preparation.md)处理。以下 Prompt 使用当前实际选定版本；已经在图像节点完成的改动不再作为视频待办，原图与改后图需要同时输入时明确各自职责。

为每份素材说明它提供形象、场景、动作、运镜、构图、风格、光影、声线、台词、旋律或节奏中的哪一项。已有参考主体时用引用保持一致，不把反推得到的发色、五官、服装或包装外观再抄一遍；只在改变细节或多主体消歧时展开外观。省略重复外观，不等于省略动作、站位、镜头和光影。

创作规划使用“角色参考”“产品参考”“动作参考”等业务角色描述；这些名称不证明资源已存在或已连接。最终节点的资源身份、真实连线、是否需要显式引用及其写入方式，按基础画布的 Prompt 资源引用路由处理。槽位与完整描述已经能唯一表达职责时，不机械引用每份素材；需要区分身份或角色时再绑定相应真实来源。输入调整后同步核对职责与引用，不依赖旧编号猜身份。

本文和场景文件中的 `【角色参考】` 等为创作示意占位。执行前必须替换为已确认的描述或按基础画布绑定，不原样送入节点，不手写位置编号或猜测内部协议。向用户展示方案时使用业务角色名，内部引用由基础画布管理；角色尚不明确且会影响创作时先解决歧义，不能擅自把某图当风格、某图当主角。

- **多宫格故事板**：参考剧情、镜头顺序与大致构图。使用干净、文字少的分镜图，补足运动、材质、声音与风格；需要更强的具体构图约束时评估独立关键帧，不保证逐帧完全对齐。
- **独立关键帧**：按顺序输入，开头写明帧序，每两帧之间补充动作方向、相机路径与状态变化，不只列图让模型猜运动。
- **参考视频**：写清参考主体、动作、运镜、节奏、特效、风格或故事机制的哪几层。机制复刻分清保留的传播功能与新设计的人物、场景、事件和台词；原片编辑明确修改范围与保留内容。
- **白模与预演**：控制空间、站位、动作路径、机位与节奏；参考图控制人物、场景、材质与渲染。对应占位物与最终主体，写出最终画面，输入去除轨迹线、坐标线和相机辅助标记。
- **音频**：区分声线、台词、旋律、节奏、声部或环境声职责，多角色分别绑定声音。连续音乐路线按通用流程确定，不把同一参考误当接续保证。

## 四段导演式写法

### 素材与角色

集中列出各素材负责的形象、声音、动作、场景与关键帧；多角色先建立清楚映射，再进入剧情。

### 整体画面

用自然句子说清主体、地点、事件、用途与主要风格，补足影响画面的条件：

- **空间**：人物与产品的位置、距离、朝向、互动对象、前后景与运动方向。
- **镜头**：景别、机位、视角、画面位置、焦点、景深和相机移动。
- **光线与色彩**：主光方向、软硬、明暗、环境色与局部强调。
- **材质与环境**：玻璃、金属、布料、水面等重要质感，以及反光、褶皱、阴影和环境响应。

选择相容的条件，不堆互相冲突的风格；摄影术语要落到可见变化。

### 分镜或时间段

```text
表达目的 + 主体、场景、站位与互动
+ 景别、机位、构图与焦点
+ 动作起点 → 行动 → 对象响应 → 结束状态
+ 运镜与时间安排 + 表情、情绪变化
+ 台词、环境音、动作音效与音乐落点
+ 下一镜或下一段的接续
```

一个短镜头抓住一个主要事件，动作、镜头与声音围绕它配合。多主体写明谁从哪里向哪里移动、与谁互动。普通重复动作可概括；关键交互、接触、转折与复杂物理需要展开准备、发生、响应和结束。不把所有微动作逐帧罗列，也不用“展开激战”等概括掩盖必须控制的动作关系。

首帧交代身份、构图与动作起点，尾帧交代动作结果与最终构图。延长用明确动作、视线、相机方向或声音承接上一段真实结果；预计结束状态只是计划，必要边界尚未理解时按通用流程补齐，不能把计划写成已观察事实。

### 全片统一要求

集中写贯穿全片的风格、光线、材质、表演尺度、画幅、节奏和声音安排；只使用当前任务确实需要的项。编辑任务注明保留范围，精确文字与数据用已确认素材或后期处理。描述中的规格不替代真实节点参数，两者须与当前模式一致。不在每镜重复“电影感、高清、高级、真实”等口号，节奏通过具体行动体现。

声音段落必须与已确认主模式一致：纯效果音只列具体动作／环境／拟音且明确无人声、无 BGM；带背景音写效果音与背景音乐／氛围背景声的关系，人声按独立决定加入；无声音明确不生成任何声音。用户给出更具体组合时以该组合为准。不能在 Prompt 写作阶段自行从一种模式切到另一种，也不能用“电影感声音”掩盖未确认的声源。

## 修改 Prompt：重写并整合，不追加补丁

先理解用户目标、受影响范围和保留项，重写相关段落，再整合成完整新版本。保留未改内容和有效细节，删除被替代的描述、重复与冲突。不把“不要 XX、要 XX”近乎原样追加，不让每轮反馈积成越来越长的否定清单。重写不是压缩长 Prompt。

把否定反馈转成具体的画面、动作、镜头、光线、节奏和声音：

- “不要拖沓” → “开场人物立即开始操作，动作完成后镜头顺势进入结果近景。”
- “不要乱切” → “镜头按打开、使用、结果的顺序推进，每次切换跟随人物动作。”
- “不要太 AI、太假” → “采用自然实拍质感，肤色柔和，布料随动作产生真实褶皱，光线从同一方向照入。”
- “不要夸张表情” → “人物用短暂停顿、视线变化和轻微微笑表达情绪。”
- “不要空泛高级感” → “用干净侧光表现瓶身反射，背景简洁，产品轮廓清晰。”
- “不要改其他东西” → “保持原片人物、动作、构图、镜头、光线和声音，仅将窗外景色替换为傍晚城市。”

正向改写必须保持准确语义。技术上必要的字幕、BGM 或合规排除可短留一条，不换着说重复，也不新增用户未要求的音乐或内容。例如“不要字幕”只排除字幕，不删原有包装文字；“不要 BGM”保留约定人声、环境音和音效，只有已选择统一配乐路线才说明音乐后期加入。

修订示例：原段落为“人物慢慢走近桌面，镜头长时间停在面部，舒缓 BGM 响起”；用户反馈“不要拖沓，不要 BGM，产品和侧光不变”。替换为：

```text
人物开场走到桌边，拿起参考产品并转向镜头；相机随手部动作从中景推进至产品近景，保留原有侧光方向与产品外观，动作完成后进入结果展示。声音由已确认的脚步、接触声和对白组成，无背景音乐。
```

其余段落一起整合成完整新版本，写入对应执行节点，不保留旧的慢动作/BGM 描述再追加反馈。是否执行新生成按通用流程中的授权规则判断。

## 用自然、具体的文字

用拿起、转身、靠近、停住、抬眼、按下、滑动、展开、露出、亮起等动作，让句子顺着画面走，不堆“构建氛围、强化叙事、实现高级视觉体验”。用行为与反应表达情绪，用构图、光线、材质与声音体现风格。

中文说明采用正常语序，写清主语、动作和必要条件，避免名词堆叠、倒装与翻译腔。语言可以鲜活，但词藻不挤掉执行细节；这一写作要求不改变三层语言各自的选择。

## 完整示例：产品广告

以下为已确认 CTA 与后期统一配乐的 15 秒结构示例，产品动作需符合真实产品。实际片长与规格按通用流程确认，不把示例当默认值。执行前将示意角色绑定为真实素材；若需要分段，按制作任务拆分以下描述。CTA 文字与统一音乐由对应后期任务处理，不将制作备注原样送给生成模型。

```text
素材：人物形象来自【人物参考】，杯子外观来自【产品参考】。保持人物和产品一致。

一条节奏明快的实拍产品短片。清晨办公室里，人物把杯子放进通勤包，转身出门，最后到工位打开杯盖。桌面靠窗，前景是杯子与包，背景办公用品柔和虚化。窗外侧光勾出杯身轮廓，金属反射干净，包的布料随手部动作产生褶皱。画面色调清爽自然。

0–4 秒：低机位近景，杯子在画面中央，包口位于右侧。人物从左侧伸手拿起杯子，放进包内并拉上拉链。镜头跟着手向右轻移，杯子进入包里后焦点落在收拢的包口。拉链声清楚，动作紧凑，结束时人物提起包。
4–9 秒：中景侧面跟拍，人物带包走过窗边，自然光依次扫过侧脸和包。人物走到门口后回头轻轻点头，镜头顺着前进方向切到工位。脚步声与包落桌的声音衔接。
9–15 秒：从桌面近景开始，人物取出杯子、放稳、打开杯盖，动作一气呵成。镜头小幅推进，焦点停在杯子和人物的手，保留自然阴影与接触关系。人物抬眼微笑，结尾稳定展示产品，画面侧边给已确认的 CTA 留出位置与阅读时间。

整体动作利落，镜头跟随动作变化，产品始终清晰可识别。声音由脚步、拉链和杯盖声组成，无背景音乐；结尾保留上述侧边留白，不生成 CTA 文字。
```

## 编辑 Prompt

按“范围 → 修改 → 保持”写明时间段、区域或对象，目标变化与必要的光影、反射、材质、遮挡和边缘融合，以及保留的时间线、人物、动作、镜头、构图、光线、场景和声音。参考重做则写“参考哪一层、重新创作什么”，不混用“其余保持原片不变”。

写完核对当前版剧本、定时分镜和任务覆盖一致；每镜可见事件与结束状态、视听细节、台词与文字语言、事实依据完整，无旧描述或冲突，无未填写的示意占位。素材职责和真实绑定一致，时间段落在当前任务范围内。精确后期文字列在制作方案中，生成描述只留出需要的位置与停留，不指望模型代替排版。规格、执行和授权检查按通用流程；此处为提交前检查，不是生成后自动验收。
