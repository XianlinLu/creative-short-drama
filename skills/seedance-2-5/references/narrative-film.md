# 影视与叙事

通用执行与 Prompt 规则按主文件必读项执行；本文仅补充故事、镜头、表演与叙事延长的导演方法。

用于微短剧、影视短片、品牌故事、概念片、预告、情绪段落和连续长镜头。采用轻量叙事流程，不默认复制完整影视工业管线。

## 一、创作起点与已有约束

- 一句话故事；
- 主要人物及关系；
- 起因、转折和结尾；
- 已有片长要求、比例和风格；片长区分硬约束、偏好和待推导；
- 角色、场景和关键道具参考；
- 对白、旁白和声音方向。

以上允许由用户材料与 Agent 的创作提案共同补齐，不要求用户预先写好故事。用户未定片长时，先形成剧本与粗分镜，再推导内容所需时长。固定广告位、已锁定音频或原片时间线从一开始参与设计。

## 二、Logline 与 Beat Sheet

先写一句话：

```text
谁，为了什么，在什么阻碍下采取什么行动，最终发生什么变化。
```

再按内容需要拆为若干节拍；中等复杂短片可从 4–8 个开始，简单片段不必凑齐：

- 建立人物和空间；
- 触发事件；
- 行动或冲突升级；
- 转折；
- 选择或结果；
- 余韵或可延展结尾。

短片应根据内容需要组织故事，不照搬长片结构。每场只设置一个主要戏剧目标，并写清：人物想要什么、阻碍是什么，以及场景结束时发生了什么变化。镜头切换以动作、视线或声音为依据，给情绪停顿与连续表演留足时间。

节拍表达事件或情绪变化，不等于固定秒数、一个镜头或一次生成。先明确观众在每个阶段知道什么、期待什么，以及变化如何得到回应。

## 三、从剧本到分镜

先把节拍展开为可表演的场景剧本：场景与时间、人物目标、动作及因果、对白/旁白、必要环境音和动作音效。重要转折写出准备、发生、结果和人物反应；日常重复动作可以概括。每个场景结束时应能指出信息、关系或情绪发生了什么变化。

再写粗分镜。先确定镜头的必要性、景别、空间关系、动作和声音；尚未计时时使用节奏描述或时长范围，不机械填写精确时间码。完成自然语速、动作和停顿的计时后，形成定时分镜，再拆为制作任务。

每个镜头写：

```text
叙事功能 + 起始状态 + 人物动作/阻碍 + 可见变化 + 镜头 + 声音 + 结束状态
```

对话镜头补充：

- 说话人；
- 听者反应；
- 视线方向；
- 动作与台词的先后；
- 是否需要正脸口型。

通过停顿、呼吸、视线、身体动作及与物体的互动来表达情绪，不只写“悲伤、愤怒、震惊”。

镜头切换应有信息或情绪理由。一个节拍可以跨多个镜头，一个镜头也可以完成多个短节拍；一次生成能覆盖哪些镜头，留到制作规划时依据连续性与当前能力决定。剧本、粗分镜与计时存在冲突时，回到相关场景调整，不用生成任务长度替代叙事判断。

## 四、资产深度

创作阶段识别必要资产及其职责；制作方案形成后再按需准备，不把全套人物设定图当成写剧本的前置条件。仅为影响跨镜一致性或关键表现的内容补充资产：

- 主角和重要配角；
- 反复出现或需要特写的产品/道具；
- 空间关系重要的主场景；
- 固定声线或对白音频。

普通背景杂物不单独设计。人物三视图、场景图、道具图只在后续多个镜头确实会复用或单个关键镜头需要精确约束时创建；优先使用已有可用素材。

## 五、长镜头

长镜头适合：连续表演、空间探索、动作接力、品牌体验和情绪积累。不要因为模型支持较长时长就强行一镜到底。

规划：

1. 明确镜头起点和终点；
2. 设计 3–5 个视觉/叙事节点；
3. 每个节点由动作、遮挡、视线、光线或声音触发下一个阶段；
4. 给镜头留停顿和信息读取时间；
5. 复杂动作只保留一个高潮。

示例骨架（假设内容计时后确定为 30 秒，仅用于展示定时分镜，不表示单次生成能力）：

```text
0–5 秒：镜头从____位置开始，人物位于____，一边____一边让观众看清空间关系；
5–12 秒：人物为____目标采取____行动，镜头沿____路径跟随；
12–20 秒：____阻碍进入，人物作出____反应，镜头随动作改变距离或方向；
20–26 秒：人物发现____并改变选择，____声音与这一转折同时出现；
26–30 秒：人物停在____位置，视线朝向____，动作进行到____阶段，以清楚的声音或动作节点结束，供下一段接续。
```

## 六、叙事延长

一条叙事成片需要多轮生成时，默认使用[单条成片的串行延长主链](sequential-extension-chain.md)：先只做起始段，真实结果就绪后一次创建一个延长节点。连续表演、同一人物／产品、空间探索、未完成动作、连续运镜或声音尤其必须优先延长；跨时空、彻底换场或风格变化先设计可生成的转场桥，不能只因“换了场景”就并联创建普通视频节点。片长本身不决定节点数。

反复出现的转场物体按连续角色处理。以翻书为例，同一本书的封面、页厚、开合角度、手位、翻页方向、纸张形变、相机和声音必须沿真实结果继承；每页通向不同世界仍是一条延长链。多个节点共享书本参考图，不代表它们共享翻页的动态状态。

先把全片规划为一条主链，用起始段建立人物、场景、光线、表演和声音基线，并沿真实结果逐轮延长。只有用户明确确认硬切蒙太奇／并联制作／独立返修，或实时能力经核验无法延长时，才在对应断点另开连续性块。分块是制作路线决定，不能由剧本场次自动推导。

规划时记录目标边界；执行延长前，记录真实源视频的边界状态：

- 人物位置、朝向、动作阶段和情绪；
- 场景、时间、光线和天气；
- 相机位置、运动和景别；
- 道具状态；
- 对白、环境音、动作音效、已有或已要求的音乐和节奏；
- 下一节拍。

提示词不能只写“继续”。要写如何衔接、接下来推进的事件和目标结束状态。每轮应有清楚、可执行的动作与叙事目标；可以覆盖多个短节拍，也可以只完成长节拍的一部分，不强制与节拍一一对应。

计划结束状态不能当成生成结果。为下一段确定接续所必需的素材理解，按基础画布的媒体理解路由执行；它不同于主动评价观感并重抽。无法可靠取得实际边界时标记未知，不编造位置、动作或声音，也不据此猜测接续。视频提交后的交接与恢复遵守基础画布规则。

从可识别的动作、视线或声音节点承接：动作未完成时接续其方向、速度和接触关系；视线引出新事件时写清被观察对象与空间位置；对白接续时保留说话人、听者反应及呼吸停顿。需要切镜、换场或跳时间时，写清触发变化的剧情事件和新场景的起始状态，使观众能理解时间与空间的变化。

## 七、多角色与复杂动作

- 多角色先列清身份、关系与素材职责；已有参考直接使用，不要求先生成角色图再写剧情；
- 肢体接触拆成“接近—接触—结果—反应”；
- 精密手部、武器握持、拥抱、群体战斗优先用白模、参考视频、遮挡或切镜；
- 复杂战斗拆成蓄力、释放、命中、反应；
- 对角色外观使用引用，不在每个镜头重新描述。

## 八、声音

- 对白、旁白、环境音和动作音效在镜头脚本阶段写入；
- 背景音乐可以作为标明待确认的创作建议与完整方案一起呈现；只有用户要求、确认或明确委托覆盖它时才制作或添加，不为提出建议先单独索要一次许可。剧情直接要求的画内声源按声音设计处理，不等同于额外添加 BGM；
- 不为了音乐卡点破坏对白、动作和口型；
- 台词与时长不相容时，先讨论延长片长、调整结构或压缩台词的取舍，确认后执行，不擅自改台词或强行塞进固定时段。

## 九、专项检查

- 是否已有适合任务规模的 Logline、Beat Sheet 和场景剧本；
- 每场是否有目标、阻碍和变化；
- 人物、场景和关键道具是否有明确素材职责与正确绑定，必要引用是否能稳定区分身份；
- 粗分镜、计时与定时分镜是否来自同一版剧本；
- 镜头与生成任务是否分别规划，未被固定段长牵制；
- 每段是否有明确目标结束状态，且与实际源视频边界分开记录；
- 延长是否从可识别的动作、视线或声音节点开始，并保持动作阶段、空间关系与表演接续；
- 声音是否在脚本中，而不是最后才补。
