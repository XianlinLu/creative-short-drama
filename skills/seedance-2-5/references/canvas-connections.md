# Lumi 与 Lumina 的画布连线

本手册用于写入生成节点、接续已有会话，以及修复已有画布上的断线。编剧、资产确认、首段和逐段延长的先后顺序见[人物与录音流程](cast-and-dialogue.md)。

## 找到本画布的操作入口

火山引擎 Lumi 使用当前会话注册的 Canvas 工具及本地技能目录。BytePlus Lumina 使用其当前会话的画布工具及技能目录。分别读取本宿主可用的图操作、模型能力与质量参考。能取得 ba-canvas 或 lumina-canvas-quality 时按其协议操作；同类能力在当前宿主以其他名称提供时，按实际注册的名称和输入格式调用。每次从当前画布重新取得节点 ID、素材 ID、模式及可用端口，不跨产品或跨画布复用这些值。

在试音节点上选择能读图片并输出所需人物语音的模式，检查当前模型是否支持该用途。Lumi 音频面板可能同时列出「文生音频」「图生音频」「音频参考」「文本音频生音频」；只有选中项生效。图片输入能生成音效时，还需确认其人物朗读能力。正式对白选择能将上游试听录音用作音色参考并朗读指定文本的模式。Lumina 使用当前界面或模型规范中的等价选项。参考区已经出现图片或录音时，仍须核对所选模式是否消费这一输入。

## 先列出应有的边，再逐个目标写入

从已确认的角色表、台词表和当前段的分镜构造所需连接，独立于当前画布已有的边。每项登记源节点 ID 与资源、目标节点 ID、输入用途，以及段号或角色与台词编号。

| 目标 | 必须从哪些节点直接连入 |
| --- | --- |
| 出镜发声者的直接试音或有声试演视频 | 该人的定稿三视图 |
| 从有声试演提取的试音 | 宿主支持时连接并绑定真实试演视频；文件回传节点无输入端口时登记来源，将回传音频实际连到正式对白 |
| 某人的每条正式录音 | 该人的已选试音。两个人的对白分别接各自的试音 |
| 首段视频 | 该段分镜文本、每位出镜角色的定稿图、每条实际使用的正式录音，以及本段其他选用素材 |
| 当前延长段 | 上一段真实视频接延长来源，另接当前段的分镜、出镜角色图、正式录音及其他选用素材 |

分镜母稿可以保存在便签。有些便签能显示全文，却没有可连接的输出。此时将当前段的镜号、时间、动作、台词及声画落点摘入**有文本输出端口**的节点。Lumi 可用「添加节点 → 文本 → 手动输入」；Lumina 查找对应的可连接文本输入。保存正文，回读文本输出后，直接连至该段视频。同版同段文本节点可复用。单纯复制到视频提示词会漏掉分镜这条边。

## 在宿主中执行并验收

1. 复用已有的同版源和目标节点。用宿主图写入工具显式连接源的输出与目标的输入。使用画布界面时，从源节点右侧输出连接柄拖到目标左侧输入连接柄。检查线两端所指节点；拖动卡片会改变位置，无法建立连接。
2. 打开目标设置，将源资源解析到相应的参考素材卡、音色参考、文本输入或延长源。若连接动作已经完成绑定，直接核对即可。正式对白只录原句并附表演指令；音色由绑定的试音提供。
3. 保存后重新读取当前图。逐对比对方向、两端真实 ID 及端口用途，并回读目标**选中的模式**与解析后的输入资源。凡有“预期但未出现”的边，仅补该边并复查，避免重复创建节点、边或媒体任务。检查同一角色和同一段的对应关系，总条数相同也可能错接。关闭并重新打开画布或用独立图读取，确认连接仍在。
4. 当前阶段只有在每个应有输入都具备持久连线、目标资源绑定和兼容的选中模式后才可提交。入口、端口容量、语音能力或资源状态不满足时，指出具体源、目标、缺少的用途及可选处理，留在本阶段。禁止自动退回普通文字转语音、默认声线或缺少本段素材的独立视频。缩放与平移影响线的可见范围，可在交付时定位到对应角色或视频节点。
5. 修复存量画布时，分别报告实际补线、原本就有的边、已验证的当前输入，以及旧媒体生成时使用的输入。事后补线可供后续执行使用；旧媒体是否采用该输入需查看原任务可核验的提交记录。修线本身不触发重跑或扣点。已有任务在途时保留其任务号和结果。
