# 跨境与本地化

通用执行与 Prompt 规则按主文件必读项执行；本文仅补充 Locale Pack、文化适配、音画本地化与母语人工复核。

用于同一母版进入多个国家、地区或语言市场，包括电商广告、UGC、口播、产品说明、品牌短片和培训内容。

## 一、跨语言场景示例

以下仅演示语言分层：用户用中文要求面向日本市场的日语广告，未要求英文 Prompt。对话与 Prompt 叙述使用中文，视频台词和显示文案使用日语。假设已确定 15 秒交付片长：

```text
制作一条面向东京年轻上班族的温暖产品短片。

0–4 秒：人物发现问题，停下手中的动作，用日语说：“時間がない！”
4–10 秒：使用用户提供的日语产品录屏展示操作，保留已核实的按钮文字“今すぐ試す”。
10–15 秒：使用用户提供的品牌标识资产收尾，后期加入日语 CTA“無料で始める”。

对白、字幕、界面文案与 CTA 使用已确定的日语文本；品牌名和注册标识保持用户提供的原样。
```

此例不要求切换沟通语言，也不意味着跨境视频应使用英文 Prompt。其他用户语言或明确的 Prompt 语言要求按三层语言规则处理。真实 UI 和精确文字由正确语言的素材或后期负责；执行时把生成片段、录屏和后期拆成对应任务，不把制作脚本整体交给一个生成节点。

## 二、每个市场建立 Locale Pack

至少包含：

- 分别记录对话语言、Prompt 叙述语言和视频内容语言；切换市场只更新相关内容语言，不自动改变前两项；
- 国家/地区与语言变体；
- 目标人群和称呼方式；
- 经确认的翻译、术语和发音；
- 币种、单位、日期、价格与 CTA；
- 禁用表达和必要披露；
- 字幕、配音和口型策略；
- 需要替换的场景、人物关系、节日、手势或生活方式；
- 目标渠道的比例、安全区，以及母版/渠道时长是硬约束、偏好还是可调整项。

不同市场分别维护，不用一个“通用外语版”覆盖所有地区。

## 三、先适配文化，再翻译

先判断：

- 原版所针对的痛点和欲望在目标市场是否成立；
- 场景、人物关系、幽默和情绪是否自然；
- 节日、饮食、着装、手势和居住环境是否合适；
- 产品使用方式、价格和 CTA 是否适用；
- 平台或监管披露是否需要改变。

保留信息功能和情绪，允许改变句长、语序和例子。不要逐字翻译。

## 四、锁定不可改资产

- 品牌名与产品型号；
- 法律、风险和必要披露；
- 认证、数据及其来源；
- 固定 UI 术语和操作路径；
- 包装中不能翻译的文字；
- 用户明确提供的官方译名。

固定品牌 Logo、产品型号、商标、官方译名和包装中的不可改文字必须保持用户提供的准确形式，不得为了统一语言擅自翻译或重绘。

## 五、选择音画方式

- **正脸口播**：本地配音 + 口型同步，按句或短段处理；
- **侧脸、远景、背影或 B-roll**：本地配音即可；
- **产品演示**：配音 + 字幕，通常不必改口型；
- **证言类**：口型不自然时用切镜或 B-roll 覆盖，不强行全程改口型；
- **纯视觉广告**：可只更换字幕、旁白、价格和 CTA。

先完成目标语言脚本与粗分镜，再以自然语速和实际音频核对时间，给字幕与必要披露留足阅读时间。目标语言所需时间变化时，按已允许范围安排停顿、镜头和补充画面；未锁定片长时重新推荐总片长，不机械继承母版秒数。母版时间线已锁定时保持约束，若自然表达无法容纳，提出精简措辞、重组镜头或放宽时长的具体取舍；涉及已确认内容的变更时再确认，不盲目加速配音或强行切镜。

口播句、镜头与生成任务不必一一对应。一条本地化成片需要多轮生成时默认采用串行延长主链；连续表演、口型、人物和声音尤其必须沿真实结果接续，但不得为迁就延长段长拆坏句意。已有音乐按保持要求处理；没有用户要求时不新增配乐。

## 六、同步替换清单

每个市场同步检查：

- 旁白和对白；
- 字幕；
- 画面文字；
- 价格、币种、单位和日期；
- CTA；
- 披露；
- 包装和 UI 中需要保留或替换的部分；
- 落地页与视频承诺。

## 七、母版与变体

仅在用户明确要求多市场或多语言版本时执行以下流程：

1. 先建立 Master，避免包含仅因原版拍摄地区而偶然出现的元素；
2. 把语言、价格、人物、场景、CTA 和披露设置为独立变量；
3. 为每个 Locale Pack 生成独立版本；
4. 文件名中包含地区、语言、比例、时长和版本信息；
5. 市场差异大时，重写 Hook 和场景，而不只是更换字幕。

示例（假设目标语言计时后确定为 25 秒，仅为定时结构示例）：

```text
将母版改为____市场、____语言版本，面向____人群。

保持：产品外观与型号、主线信息、已确认的证明，以及开场让观众产生“____”疑问的作用。
适配：人物在____场景中以当地自然的称呼和表达交流；价格使用____币种，数值使用____单位，CTA 与必要披露采用已确认的本地文案。
音画：0–8 秒正脸口播使用已确认台词“____”，按目标语言自然语速安排停顿并同步口型；8–18 秒产品演示沿用原动作，本地配音“____”与操作对齐，字幕在后期使用已确认文本；18–25 秒使用真实素材或后期展示本地报价、适用证明与 CTA“____”。
表达：按当地习惯组织句子，保持原意和事实准确；固定品牌名、官方译名及不可改包装文字按提供的原样保留。
```

## 八、专项检查

- 对话与实际 Prompt 叙述是否保持各自约定语言，未被目标市场、外语素材或示例带偏；
- 每个市场是否有独立 Locale Pack；
- 固定品牌名、商标、官方译名和不可改包装文字是否保持原样；
- 字幕、声音、画面文字、价格/单位、CTA 是否同步；
- 正脸镜头是否明确口型或遮盖策略；
- 自动字幕、专有名词、数字和发音是否标记为需要母语人工复核；
- 必要披露是否进入声音和画面；
- 落地页、库存、优惠和视频承诺是否一致；
- 目标语言是否保持自然语速，字幕与披露是否留足阅读时间；
- 母版时间线保持项与本地化可调整项是否明确，时长是否经过目标语言计时；
- 文件名与版本是否可追踪。

语言自然度、文化敏感性、广告合规和事实准确性必须由目标市场的母语或业务负责人最终确认。
