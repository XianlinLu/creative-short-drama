# 内容先行的三层循环

本文件规定创意、剧本、创作分镜必须先于规格提问、生产参数和最终 Prompt。目标是先得到值得制作的内容，再决定怎样交给 Seedance 2.5；不让工具默认值、示例秒数或 Prompt 模板反向塑造故事。

## 创作隔离区

进入第一轮内容循环时，只使用：

- 用户原始需求中已经明确的目标、受众、渠道、事实、主题、情绪、人物、产品、固定台词、禁止项和硬性片长／画幅；
- 可可靠理解的输入素材及用户明确的修改／保持要求；
- 题材本身需要的专业知识和已选场景方法。

暂不使用：未由用户给出的画幅、模型生成时长、分辨率、质量档、候选数、节点数量、模型偏好、单次生成上限、Prompt 模板或参考示例里的剧情结构。可以读取基础画布为安全、媒体理解和写入所必需的规则，但不能把其中的默认值当创作条件。未知规格保持未知，不先补一个“常用值”。

若基础画布要求先取得媒体理解授权，或缺少的信息使交付目标本身无法辨认，可先处理这一项必要授权／歧义；这类问题只让内容循环能够开始，不能顺带提前询问尺寸、时长、质量档或模型偏好。能依据用户文字和可读素材形成合理草稿时，先循环再提问，不以“想做得更准”为由提前打断。

这不是忽略用户已经给出的约束。用户一开始明确“9:16、15 秒、必须保留这句旁白”时，它们属于创作题目；若 15 秒装不下内容，应在内容循环中形成可解释的取舍方案。来源素材的真实比例是事实，不自动成为输出画幅。

内部循环只保留当前草稿、检查结论和修订后的结果，不向用户展示私密推理过程。对用户展示可审阅的创意、剧本、分镜、依据和待选择项。

## 三层依次循环

每层至少完成一次“起草 → 检查 → 修订”。发现实质问题就继续迭代，直到满足完成标准，或明确指出只有用户选择才能解决的分歧。不要为了凑次数改写同义句；循环的证据是内容问题被发现并修正，而不是声称“已思考多轮”。

### 一、创意循环

**起草**：形成一句话核心、观众体验、主要冲突／信息承诺、情绪或认知变化、开头吸引点和结尾回应。开放任务可在内部探索若干真正不同的方向，再选择最符合用户目标的一版；只有多个方向会导致真实取舍时才把精简选项交给用户。

**检查**：

- 是否回应用户目的，而不是仅堆视觉风格；
- 是否有明确变化、发现、证明或结果；
- 开头承诺与结尾是否闭合；
- 是否照搬参考素材表面元素，或被“15 秒广告”“电影感”等模板套住；
- 事实、品牌、人设与用户保持项是否被改写；
- 是否存在更简单、更鲜明且可视化的表达。

**修订与完成**：删除无作用支线和熟套装饰，强化因果、独特点与情绪／信息落点。完成时应能说明“观众为何继续看、最终得到什么”，且不依赖尚未选择的模型参数才能成立。

### 二、剧本循环

**起草**：把当前创意展开为场景和事件，写清人物／信息目标、行动、阻碍或证明、转折、结果、对白／旁白及必要声音。内容先按自然表达需要展开，不先切成模型允许的秒数块。

**检查**：

- 每场是否推进目标，删掉后是否真的有损；
- 行动是否由前因触发并产生可见结果，人物动机是否成立；
- 关键事实、产品证明、教学步骤和用户台词是否准确；
- 对白是否可说、角色是否会这样说，声音是否与行动配合；
- 是否有重复说明、无画面承载的信息、突兀转折或只写情绪不写行为；
- 开头、发展、转折与收束是否形成完整观看体验。

**修订与完成**：重写问题场景而非追加解释；合并重复信息，补足动作和反应。完成时，每个重要变化都能从剧本中找到原因、过程与结果，且形成可供分镜转译的具体事件。

### 三、创作分镜循环

创作分镜表达内容怎样被看见和听见，不是生成任务表，也不是最终 Prompt。

**起草**：将剧本转为镜头级可见事件，写出叙事功能、起始状态、主要行动、对象响应、结束状态、景别／机位／运动意图、声音关系和节奏。画幅未知时描述空间重点、视线与运动关系，不先固定精确左右边距或为某个比例裁故事。

**检查**：

- 每个剧本变化是否有画面或声音载体；
- 切镜是否服务信息、动作、视线、空间或情绪，而非按固定秒数机械切；
- 动作起点、接触、响应和结果是否连续，人物／道具位置是否可理解；
- 景别与运镜是否有表达理由，是否存在互相冲突的镜头要求；
- 台词、阅读、动作和反应能否在同一注意力时间线上成立；
- 素材只承担其适合的职责，是否为迁就现有图片而改变已定剧情；
- 首尾状态是否足以支持后续计时与制作设计。

**修订与完成**：调整镜头边界、表演、信息顺序和声音落点，必要时回到剧本或创意层。完成时，不看 Prompt 和生成参数也能理解每镜为何存在、发生什么、怎样接到下一镜。

简单单动作或局部编辑使用轻量版本：明确意图与变化 → 写动作／保持项 → 形成一个镜头的起止状态 → 检查并修订一次。无需伪造多场戏或长表格，但仍不能先写生成 Prompt 再反推内容。

## 内容母版、计时与第一次提问

三层循环完成后，形成一份**内容母版**：当前创意、完整剧本、创作分镜、声音意图、素材职责和内容所需时长估算。画布项目按通用流程把它保存为草稿 Note；未知规格标为待确认。此时仍未创建最终生成 Prompt。

然后才进入 question 关口。向用户展示足以判断的内容摘要及必要取舍，并集中询问：

- 创意、剧情、节奏和分镜方向是否需要调整；
- 未给出的输出画幅／尺寸，以及是否接受内容驱动的片长建议或有硬性片长；
- 实时确认后确实可选的清晰度／质量档；第一次询问生成声音时明确选择“纯效果音／带背景音／无声音”，涉及对白、旁白、歌声、口型或原声时另行确认人声；
- 素材修改方案、是否需要审图，以及这次是否仅修改方案或开始制作。

用户原始请求已经明确或委托的项不重复问。用户答复只更新对应项；内容反馈触发循环，规格答复进入生产映射。若用户同时修改故事并选择规格，先重做受影响的内容循环，再检查规格是否仍适用；不能为保留旧参数而压缩或扭曲新故事。

## 反馈循环与生产映射

按影响向上回溯，再顺序更新下游：

| 用户反馈 | 回到哪里 | 必须同步更新 |
| --- | --- | --- |
| 改主题、受众、结局或核心卖点 | 创意循环 | 剧本、创作分镜、计时、素材方案 |
| 改事件、角色行为、台词或信息顺序 | 剧本循环 | 创作分镜、计时、素材方案 |
| 改镜头、表演节奏、运镜或声音落点 | 创作分镜循环 | 计时、素材职责与生产分镜 |
| 只改硬性片长 | 从内容母版检查容量 | 必要时提出删改／延长方案；用户选择涉及内容时回相应循环 |
| 只改画幅、清晰度或质量档 | 生产映射 | 适配构图、资产规格与节点参数；不擅自改故事 |

内容母版和相关规格获得确认，或用户已明确委托 Agent 决定并授权制作后，才进入生产映射：把创作分镜适配到已定画幅，形成定时／生产分镜、素材任务、生成／延长／后期任务与真实依赖。生产限制若暴露内容不可实现，先提出保持意图的替代方案；需要改变创意、剧本或镜头语义时回到对应循环并再次让用户决定，不能静默让模型能力裁掉内容。

## Prompt 是派生产物，不是创作源头

最终 Seedance Prompt 只能从当前已通过的内容母版、定时／生产分镜、选定素材和确认规格派生。写 Prompt 前逐项映射“内容决定 → Prompt 中的具体表达”，不得新增母版没有的剧情、台词、角色、音乐、镜头噱头或修改事项。

Prompt 模板用于组织，不用于发明故事。模型输入长度不足时先压缩重复措辞并保留叙事核心；仍放不下时调整任务拆分。拆分或改参数不能改变内容母版的因果、角色目标和关键结果。用户反馈到来后先改母版及受影响循环，再重写完整 Prompt；不直接在旧 Prompt 末尾追加“不要／改成”补丁。
