# Seedance 2.5 完整链路分析

这套流程围绕三份相互关联的产物展开。**内容母版**记录观众将看到和听到什么，**制作任务表**记录各段如何取得素材，**任务与资源状态**决定现在能够执行哪一步。故事可以一次规划完整，多段连续成片的下一段必须等上一段实片就绪才能配置。

## 从需求到交付

| 环节 | 输入与处理 | 产出与下游条件 |
| --- | --- | --- |
| 1. 确定任务 | 识别受众、用途、交付物、已有剧本或原片，摘出用户指定的片长、画幅、固定音频、必留台词和修改范围。已有视频先判断要局部编辑、借鉴重做，还是直接剪辑。 | 一份有边界的创作任务。只要方案或 Prompt 的任务可在相应产物处交付。 |
| 2. 素材初评 | 核验图片真实格式、字节数和宽高，按当前模式比对限制。分别检查内容辨识度、事实依据、可承担的职责以及修改与保持项。 | 原始素材清单、用途、待核验项与修复选择。分镜完成后还要复核镜头适配。 |
| 3. 创意循环 | 以目标和可用素材写一句话核心，检查开头承诺、冲突、变化与结尾回应，再修订。 | 确定观众为何继续看，以及最后获得什么。 |
| 4. 剧本循环 | 把核心展开为场景和事件，检查动机、因果、可见行动、台词、声音与结果，再改写有问题的场景。 | 可表演的剧本。结构化画布项目此时建立或更新同一份“创作与分镜方案”草稿 Note。 |
| 5. 创作分镜与计时 | 把剧本变成镜头，检查起止状态、人物反应、机位、视线与声音衔接。按自然语速、动作、阅读、停顿与转场估时，同时发生的活动按同一时间线评估。 | 内容母版含剧本、粗分镜、声音意图、素材职责、片长区间和依据。超出硬片长时提出具体删改或交付取舍。 |
| 6. 内容反馈与制作确认 | 提交可审阅的母版，经宿主交互工具取得反馈。记录片长、画幅、可选清晰度、声音、素材修改、审图点、费用和本次执行范围各自的决定依据。 | 将草稿、用户已定、已委托、模式继承和待决定的事项分开记录。内容修改返回相应创作层，关键待定项阻塞依赖它的生成。 |
| 7. 生产映射 | 依已定规格将创作分镜转为定时分镜，核对素材能否支持镜头起点、构图、连续性和真实信息。为每个任务选择复用、资产编辑、生成、延长或后期。 | 制作任务表记录覆盖的镜头、真实来源、计划生成或新增时长、预计使用区间与就绪状态。一项任务可涵盖多个镜头。 |
| 8. 资产与 Prompt | 按已选方案准备衍生资产，复检并绑定真实版本。根据同一版母版、生产分镜和节点局部时间线编写 Prompt。 | 具备真实输入、参数和执行授权的当前节点。后续延长段的最终 Prompt 留到真实边界出现时编写。 |
| 9. 提交与恢复 | 按宿主协议提交当前任务，取得任务编号后交接。后续查询对应原任务，读取就绪资源，再按授权继续或转后期。 | 已提交、在途、失败、未知和已就绪分别记录。局部修订复用未受影响的成果，保留在途任务。 |
| 10. 收尾 | 检查实际输出是否包含前段，确认可交付长度、声音和来源。单段或累计结果已满足目标时直接交付。 | 简单顺序结构、剪辑草稿、已导出的成片分别标明。需要精确后期时，以真实来源完成合成并核实结果可用。 |

单动作和局部修改可将创作检查压缩为一镜的意图、动作、保持项和起止状态。已有完整剧本可直接检查其对应层。制作中始终分别记录交付硬时长、内容估时、单次生成或新增长度，再用真实素材时长校准剪辑。[创作三层循环](../skills/seedance-2-5/references/creative-development-loop.md) · [故事、计时与两张工作表](../skills/seedance-2-5/references/story-and-timing.md) · [通用制作流程](../skills/seedance-2-5/references/core-workflow.md)

## 素材怎样进入视频节点

1. **能直接承担职责的素材**绑定到相应镜头。主体图负责身份，首帧负责动作起点。例如，人物已经举起杯子的照片可以提供身份参考，拍摄“伸手拿杯”还需要合适的起始姿态。
2. **内容有效但技术超限的素材**保留原件和检测值。可换更合适的原件、用转码或缩放等确定性处理、调整参考用途。需要扩图、换装、换背景或改变姿态时，列出修改范围与保持项，再走图像编辑或生图路线。
3. **镜头缺少必要资产时**按职责补充主体、场景或关键帧。故事板用于镜头顺序和大致构图，独立关键帧用于约束具体状态，白模或预演用于空间和运动。只补能解决已识别问题的资产。
4. **衍生图交给视频前**复检真实输出的格式、大小、宽高和比例，完成已约定的选图，记录原件与衍生件关系。将选用版本同步至 Note、任务表和实际节点。视频 Prompt 从改好的状态开始描述动作；来源未知或仍超限时停在依赖处。

具体预检字段、修复选择和生图到视频的交接步骤见[素材准备](../skills/seedance-2-5/references/asset-preparation.md)。

## 用户反馈如何传回上游

| 反馈 | 回到哪一步 | 同步哪些结果 |
| --- | --- | --- |
| 改受众、核心卖点、主题或结局 | 创意 | 剧本、分镜、计时、素材方案与受影响任务 |
| 改事件、行为、台词、信息顺序 | 剧本 | 相关场景、镜头、声音、计时和下游依赖 |
| 改镜头、运镜、表演节奏、声音落点 | 创作分镜 | 接续边界、定时分镜与生产任务 |
| 改硬片长或锁定配音 | 内容容量检查 | 按真实读稿与素材时长提出取舍，必要时回到剧本 |
| 只改画幅、清晰度或质量档 | 生产映射 | 构图、安全区、资产规格与节点参数 |
| 修改已出的片段 | 原片编辑或精确后期 | 确定时间段、对象、修改项与保持项，保护已有结果 |

每次更新同一份方案，标明版本与决定依据，再重写受影响任务的完整 Prompt。原包建议按“素材与角色 → 整体画面 → 分镜或时间段 → 全片统一要求”组织。执行前把示意占位换成宿主可识别的真实绑定。分别记录沟通语言、Prompt 叙述语言和片中台词／文字语言。[Prompt、引用与修订示例](../skills/seedance-2-5/references/prompt-and-references.md)

声音会影响剧情和后期。原包给出的主模式为纯效果音、带背景音、无声音；对白、旁白、口型和原声保留另行记录。已有具体组合时沿用该选择。关键线索靠对白传递却改为静音时，要回到剧本和分镜，为线索设计可见载体并重新计时。全片统一音乐可沿真实视频接续，或在后期铺设一条已获准使用的音乐轨。[声音选择与音乐连续性](../skills/seedance-2-5/references/core-workflow.md)

## 一条成片如何逐段延长

以“每翻一页书，进入一个新场景”为例。分镜可以预先写齐所有场景。下一段实际要继承的却是上一段实片里的手位、书页开合角度、翻动方向、光线、相机运动和翻页声。这决定了建节点的时机。

| 当前状态 | 触发条件与动作 | 下一状态 |
| --- | --- | --- |
| 全片已规划 | 当前起始段所需素材、规格与授权齐备，只创建和提交起始段 | 保存主链、方案版本、段序号与任务编号，交接 |
| 已提交或在途 | 用户后续查询或要求继续时，按原编号核验。只问状态时仅返回状态 | 在途则继续等待。失败或状态未知时按宿主恢复协议处理，保留原任务记录 |
| 实片已就绪 | 若已获准继续，读取必要的实际动作、道具、光线、镜头和声音边界 | 用真实结果绑定唯一的直接上游，按实片重写本轮新增内容 |
| 当前延长段可执行 | 只创建或更新一个延长节点，只提交当前段 | 保存新任务与下一段计划，重新进入交接 |
| 所需段已就绪 | 核实输出是累计成片还是仅含新增段，并核对实际时长 | 直接交付可用结果，或将必要真实来源送入后期，避免重复拼接 |

独立制作适用于用户明确选择硬切、并联、独立版本或逐镜返修，以及实时能力不支持延长、上游有不宜继承的问题、真实来源互不相容等情形。路线变化涉及尚未委托的取舍时，先说明对连续性和可修改性的影响。单纯换景仍可通过动作、遮挡、形状、光线或声音桥接。未来段保存在任务表；阶段预览只呈现已有结构。[串行延长、状态记录与恢复](../skills/seedance-2-5/references/sequential-extension-chain.md)

## 七类场景如何接入主线

场景规则改变剧本怎样写、素材怎样用，以及最终怎样验收交付物。复合项目可以组合使用，例如先按影视叙事建立品牌故事，再按本地化流程制作已要求的市场版本。

| 场景 | 分支与处理顺序 | 回到主线时带回的产物 |
| --- | --- | --- |
| [影视与叙事](../skills/seedance-2-5/references/narrative-film.md) | 一句话故事 → 人物目标与阻碍 → 情节节拍 → 场景剧本 → 镜头与声音。长镜头用动作、视线或声音串起视觉节点，多角色场面明确站位与反应。 | 可表演的场景、创作分镜、连续性资产，以及供延长的目标边界 |
| [参考复刻](../skills/seedance-2-5/references/viral-remix.md) | 原片复刻先拉片，记录时间段、动作、运镜、节奏与替换映射。爆点复刻先做机制卡，提取开场疑问、情绪曲线与证明方式，再用当前题材重写剧本。 | 原片骨架与保持清单，或机制卡、新脚本和重新估时的分镜 |
| [电商与广告](../skills/seedance-2-5/references/commerce-advertising.md) | 从真实产品、受众、主卖点与证据选择广告机制。效果广告安排演示、证明和 CTA，品牌片安排情境、体验变化和品牌落点。门店／SKU 批量任务先核对代表版本。 | 有来源的产品演示、证明与行动文案，需要多版本时附母版和变量矩阵 |
| [跨境与本地化](../skills/seedance-2-5/references/localization.md) | 按市场建立 Locale Pack，锁定品牌与术语，适配情境后翻译。按目标语言自然语速重算，选择字幕、配音或口型策略，同步价格、披露、CTA 与落地页。 | 可追踪的市场版本，交由母语或业务负责人复核 |
| [CG 与设计可视化](../skills/seedance-2-5/references/cg-design.md) | 白模或预演确定空间、机位和动作，参考图确定外观材质。游戏动画核对动作与响应，建筑家居核对空间关系与相机路线，工业装配核对部件顺序和技术资料。 | 结构保持项、运动预演、渲染参考、需精确后期添加的标注 |
| [知识与产品演示](../skills/seedance-2-5/references/education-demo.md) | 从可验证的学习目标安排讲解、演示、观察与检查。软件功能用真实界面和操作路径，设备培训用正式资料核实步骤与警示。 | 教学脚本、真实录屏或实拍清单、字幕标注与专业复核项 |
| [编辑与版本化](../skills/seedance-2-5/references/editing-versions.md) | 局部编辑确定范围、改动与保持项；参考重做重新规划镜头；延长从真实源片边界开始；双片转场匹配前尾和后首。多比例重新构图，短版重选信息，多版本从同一母版派生。 | 局部编辑方案、转场或延长任务、可追踪的版本，按精度要求进入后期 |

## 交接记录与执行依赖

- **创作层**保存内容母版、分镜、计时、素材职责、反馈与待定项。原包入口列出不同任务的阅读顺序及轻量路线。[Skill 入口](../skills/seedance-2-5/SKILL.md)
- **画布层**由外部 `ba-canvas` 提供实时模式、资源身份、节点连线、提交、查询与恢复。执行记录保存真实任务编号、来源、当前阶段和下一步，内部标识与临时地址留在宿主记录中。Note 只承载可审阅的方案。
- **质量层**由外部 `lumina-canvas-quality` 提供图像资产、一致性、视频制作和剪辑保护方法。生成前检查同版剧本、Prompt 和素材；生成后按任务核验资源与接续所需事实。观感评价与重抽按用户反馈处理。
- **后期**按宿主能力分流。简单顺序预览可用 VideoCompose。精确裁剪、字幕、Logo、混音、多轨、严格时长或导出走 VividCut 等适用路线。交接时注明当前可用资源、仍在途的任务、剩余依赖以及用户下一次查询或继续时应恢复的位置。[后期与交付](../skills/seedance-2-5/references/editing-versions.md)
